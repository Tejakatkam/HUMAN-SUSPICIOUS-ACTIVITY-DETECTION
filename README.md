# 📖 About

The **Human Suspicious Activity Detection System** is an AI-powered desktop application that detects suspicious human activities from CCTV surveillance footage using a **ResNet-based Deep Learning model**. The system analyzes video frames, identifies potentially suspicious behavior, and presents the results through an intuitive **Tkinter GUI**, helping improve security monitoring and reducing manual surveillance effort.

---

# ✨ Features

- 🎥 CCTV Video Analysis
- 🤖 AI-Based Suspicious Activity Detection
- 🧠 Deep Learning using ResNet
- 🖥️ User-Friendly Tkinter GUI
- 📂 Video Upload Support
- ⚡ Real-Time Prediction
- 📊 Automated Activity Classification
- 🔒 Enhanced Surveillance Monitoring

# ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/TejaKatkam/Human-Suspicious-Activity-Detection.git
```

### Navigate to the Project

```bash
cd Human-Suspicious-Activity-Detection
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```

---

# 🧠 AI Model

The application uses a **ResNet Deep Learning model** for image classification to identify suspicious activities from surveillance footage.

### Workflow

- Video Frame Extraction
- Image Preprocessing
- Feature Extraction using ResNet
- Activity Classification
- Prediction Display through Tkinter GUI
